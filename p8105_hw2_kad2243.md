## Description of the NYC transit data set

The NYC Transit Subway Entrance and Exit Data set contains **1868** rows
and **17** columns. The variables included in the set are: **line,
station_name, route1, route2, route3, route4, route5, route6, route7,
route8, route9, route10, route11, entry, vending, entrance_type, ada**.
Line describes which major street or avenue is described, station name
is the station or stop, route is the trains stopping at the station,
etc. Following import of the raw data, variable names were renamed to
include underscores, variables of interest were selected, and the
variable “entry” was changed from YES/NO to TRUE/FALSE. The data are not
particularly tidy, routes are captured across columns rather than as
distinct observation, so route and route name are combined, with some
route variables containing blanks for missing values and some containing
NA.

## Data clean

For all Trash Wheel Data - Renaming variables using clean_names and
manually renaming long variables - omitting rows that do not include
dumpster-specific data - rounding sports balls to the nearest integer
and converts the result to an integer variable (using as.integer)
-Adding new var to each set for trash wheel identification -Changing
year to numeric, changing plastic bottles to numeric

``` r
trash_mr = 
    janitor::clean_names(trash_mr) %>%
    rename(weight_t = weight_tons, volume_y3 = volume_cubic_yards, cig = cigarette_butts ) %>%
    filter( dumpster != "") %>%
    mutate( sports_balls = as.integer(round(sports_balls,0)), trashwheel = "mr", year = as.numeric(year),)

trash_prof = 
    janitor::clean_names(trash_prof) %>%
```
